# Contributing / 贡献指南

Thanks for helping keep this list useful and trustworthy.  
感谢你帮助维护这份目录的实用性与可信度。

## What belongs here / 收录范围

- Image-creation skills, reusable workflows, prompt systems, or closely related open tools.
- The project must be publicly accessible and have clear installation or usage guidance.
- Its license must be visible. Projects with restrictive or non-commercial terms are welcome, but must be labeled accurately.
- One entry must add a distinct capability; do not submit duplicates or abandoned links.

收录图像创作 Skill、可复用工作流、提示词体系及高度相关的开放工具。项目须可公开访问、具有清晰的安装或使用说明，并展示许可证。限制性或非商业许可证的项目也可收录，但必须准确标注；请勿提交重复或失效链接。

## Entry format / 条目格式

```md
- [Project Name](https://github.com/owner/repository) — One concise bilingual description. / 一句简洁的中英双语说明。`License`
```

Example / 示例：

```md
- [Example Skill](https://github.com/owner/repository) — Creates editorial-style images from a reference photo. / 根据参考照片创作编辑风格图像。`MIT`
```

## Submission checklist / 提交检查

- [ ] The link works / 链接有效
- [ ] The license label matches the source project / 许可证标注与源项目一致
- [ ] The entry is in the best-fitting category / 条目位于合适分类
- [ ] The description explains the practical outcome, not just marketing language / 描述说明实际能力而非营销文案
